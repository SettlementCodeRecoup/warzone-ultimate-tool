## 🛠️ Troubleshooting

- **Menu not opening:** Ensure the tool is running as Administrator and the game is in borderless/windowed mode.
- **ESP not showing:** Check that your game resolution matches your desktop resolution and that you are in a match.
- **Tool crashes:** Disable antivirus temporarily or add an exclusion for the tool folder.
- **Aimbot not working:** Adjust smoothness and FOV settings; ensure the target is within FOV.
- **Overlay not visible:** Toggle streamproof mode off; some recording software blocks overlays.
